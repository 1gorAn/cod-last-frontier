ЦОД: Последний рубеж

Браузерная игра: оборона дата-центра, управление энергией, охлаждением
и доставкой боеприпасов. Десять непрерывных волн, разные локации и боссы.
Стек: React, Phaser 3, TypeScript, Vite.

Репозиторий: https://github.com/1gorAn/cod-last-frontier
Адрес после публикации: https://1gorAn.github.io/cod-last-frontier/

Локальный запуск (Node.js 22.23+):
  npm ci
  npm run dev

Проверки и сборка:
  npm test
  npm run build
  npm run preview
Открывайте адрес Vite с путём /cod-last-frontier/.

GitHub Pages:
1. Отправьте проект в ветку main указанного репозитория.
2. Settings → Pages → Build and deployment → Source: GitHub Actions.
3. Во вкладке Actions дождитесь завершения Publish game to GitHub Pages.
   Если первый запуск был до включения Pages, нажмите Re-run all jobs.
Каждый следующий push в main проверяет тесты, собирает и публикует игру.
Ручной повторный запуск: Actions → Publish game to GitHub Pages → Run workflow.

Публикуется только dist/, исходники и изображения хранятся в репозитории.
node_modules/, dist/, локальные настройки и .env не включаются в Git.
Игра работает без сервера и API-ключей. Сохранения хранятся в браузере;
для переноса из локальной версии используйте экспорт и импорт JSON.

Управление:
Выбрать объект, затем свободную клетку. ESC — отмена строительства.
Нажать на здание — улучшение, ремонт, настройка ПВО и пополнение.
Перетаскивание — обзор, колесо / два пальца — масштаб.
Пауза доступна до атаки. После запуска все десять волн идут непрерывно.
На телефоне каталог открывается кнопкой «Строить».
